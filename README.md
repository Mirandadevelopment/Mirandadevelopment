## 👨‍💻 Sobre mim

Sou **Allan Miranda**, desenvolvedor **Full Stack** focado no ecossistema **Node.js, TypeScript e React**, especializado no desenvolvimento de aplicações web, integrações de APIs, automações no Discord e arquitetura para servidores FiveM.

🎓 Cursando **Análise e Desenvolvimento de Sistemas** na **Anhanguera Unopar** (Piabetá, Magé/RJ), aplicando padrões de projeto, arquitetura limpa e boas práticas de desenvolvimento de software em projetos reais.

### 🎯 Principais Competências
- **Aplicações Web Modernas:** Desenvolvimento de interfaces reativas e APIs com Node.js, React, tRPC e Drizzle ORM.
- **Integrações de Pagamento & Webhooks:** Implementação de gateways (ex: Pix) e integração de sistemas em tempo real.
- **Automações & Bots:** Desenvolvimento de bots complexos com `discord.js`, gerenciamento de banco de dados e sistemas de gestão.
- **Ecossistema FiveM:** Criação e otimização de scripts (QBox, VRP, vRPex), integração web/bot e arquitetura de banco de dados.
